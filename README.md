# أنوبيس ترافيل | ANUBIS TRAVEL

الموقع الإلكتروني الرسمي لخدمات النقل السياحي والليموزين الفاخر في جمهورية مصر العربية.

## ✨ المميزات
- تصميم ملكي فاخر باللونين الأسود والذهبي مع دعم كامل للغتين (العربية / English).
- حاسبة أسعار تفاعلية لحساب تكلفة الرحلات والتوصيل وحجزها مباشرة عبر الواتساب.
- جداول أسعار تفاعلية لرحلات اليوم الواحد، والتوصيل من وإلى مطار القاهرة، والرحلات متعددة الأيام بين المحافظات.
- استوديو QR كود لمشاركة الرابط بسهولة على شاشات الموبايل.
- لوحة تحكم إدارية مستقلة.

## 🚀 التشغيل المحلي
يمكنك فتح ملف `index.html` مباشرة في أي متصفح، أو تشغيل السيرفر المحلي عبر تشغيل `start-server.bat`.
